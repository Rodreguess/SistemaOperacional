🖥️ Sistema Operacional - Simulação em C++
  Este projeto é uma simulação didática de um Sistema Operacional, desenvolvida em C++ com princípios de programação orientada a objetos. Ele visa demonstrar e aplicar conceitos fundamentais de um SO real de forma simplificada.

📚 Funcionalidades Principais
  - Gerenciamento de Processos: Criação de processos com atributos como ID, prioridade, tempo de CPU e consumo de memória.
  - Kernel Centralizado: Atua como o núcleo do sistema, responsável pela inicialização, criação de processos e coordenação geral dos recursos.
  - Escalonamento de CPU: Implementa um escalonador FIFO (First In, First Out) que prioriza processos com base em seu nível de prioridade. Processos são executados em ciclos de tempo simulado.
  - Gerenciamento de Memória: Simula a alocação e desalocação de memória para os processos, controlando o espaço livre e ocupado no sistema. Processos só são executados se houver memória disponível.
  - Monitoramento do Sistema: Exibição clara do estado dos processos (prontos, executando, finalizados, aguardando memória) e do uso da memória.

🛠️ Tecnologia
  - C++: Utilizado para a construção modular e orientada a objetos do simulador.
